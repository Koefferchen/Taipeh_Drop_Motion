------------ Experimentation ------------



1.  Turn on all required Electronics
    >> the PC (If the display doesnt go on, plug out and in the USB cable)
    >> the front light (huge light)
    >> the top light (small, machine is below the table left)
    >> the camera (power on)

2.  Open "CL-NavigorN" for the Control of the Laser

3.  Open "60fps_5000.pcs" (PFV Symbol) for the Camera Control
    >> Choose Shutter as "1/15385 sec"

4.  Open "PIMicroMove" for the Piezo Motor Control (Move Sample)
    >> the "Q-545" / "SN 0416" is the only Piezo we need 

5.  Sample Preparation 
    >> there are 4 different samples, but dried PDMS is the easiest to start
    >> the droplet is always twice-boiled water (not destilled)
    >> sample cleaning is done best with tape
    >> sample cleaning with suitable chemicals would be best (we dont have)
    >> sample cleaning with boiled water could help (or worsen it)
    >> place the sample below the beam

6.  Laser Calibration (only once)
    >> Rotate the beam until the laser gets a signal. The laser can only operate in a certain window of distance since it uses diagonal beams.
    >> Once the laser has horizontal sight contact with the beam, lower the beam until it barely touches the sample. Then, lower the laser until the point where it starts loosing vertical sight contact with the beam. From there, move the Laser up by 300um. 

7.  Beam Calibration 
    >> Let the beam down until it barely touches the sample.
    >> Now move the beam up 250um above the sample.

8.  System Settings
    >> Make sure the Piezo motor is in "Home" position before each measurement
    >> Make sure to use only parts of the sample that are flat and clean
    >> Reset the Distance measured by the laser to 0 before measurement.

9.  Measurement of static & dynamic adhesive Force
    >> Pour a droplet of fixed volume between beam and laser on the sample.
    >> Make sure that the droplet is centered in the trajectory of the beam.
    >> Drive the droplet into beam until they touch     
    >> Pulling method: drive back at constant speed
    >> Pushing method: drive further throgh the drop at constant speed
    >> The max. force measured is approx the static force
    >> The convergent value of the force is approx the dynamic force

10. Parameters to be measured
    >> Whole force profile of the measurement
        >> static force
        >> dynmaic force
    >> drop volume 
    >> initial drop contact line (untouched)
    >> initial drop contact angle (untouched)
    >> dynamic advancing & receding contact angle (while equilibrium movement)
    >> room temperature (thermometer + AC on at approx 28°C)
    >> room humidity (need new devive)
    >> duration of experiment (to estimate evaporation)
    >> time between consecutive experiments (to estimate material memory impact)
